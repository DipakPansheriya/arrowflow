Overview

1. Getting Started

ArrowFlow is a standalone 64-bit Windows desktop application compiled using PyInstaller. It automates keyboard arrow presses, mouse clicks, and tab file switching targeted at active Visual Studio Code editor windows.

Executable: ArrowFlow.exe | Target OS: Windows 10 / 11 | Architecture: x64
2FA Security

2. Two-Factor Authentication (TOTP)

ArrowFlow features multi-factor authentication powered by Firebase. Upon launch, enter the administrator access password followed by the time-based 6-digit OTP code from Google Authenticator or Microsoft Authenticator.

Default Password: deep@2026 (SHA-256 protected).

First Launch: Scan the displayed QR code or enter the 16-character Secret Key in your Authenticator mobile app, then enter the 6-digit confirmation code.

Subsequent Logins: Enter your password and the current 6-digit OTP code from your Authenticator app.

Firebase Persistence: The Authenticator secret key is created once and stored securely in Firebase Firestore, allowing seamless recovery if your phone is lost or replaced.

Configuration

3. VS Code Target Selection

ArrowFlow enumerates top-level active windows via Win32 API and populates the Target Window combobox dropdown.

  • Windows matching Visual Studio Code are auto-highlighted.
  • Clicking Refresh updates the window list if VS Code was opened after ArrowFlow.
  • Keypresses and clicks are delivered via Win32 messaging to the selected target window handle (HWND).
Configuration

4. Arrow Press Range

The ARROW PRESS RANGE controls the bounds of randomized activity generated per 60-second minute cycle.

MIN PRESSES Minimum target (Default: 10)
MAX PRESSES Maximum target (Default: 40)
Core Engine

5. Random Per-Minute Target

At the beginning of each 60-second window, ArrowFlow generates a single integer target N between MIN and MAX.

Example per-minute targets:

● Minute 1: Target = 22 (22 Keyboard Events, 22 Mouse Clicks)

● Minute 2: Target = 34 (34 Keyboard Events, 34 Mouse Clicks)

● Minute 3: Target = 15 (15 Keyboard Events, 15 Mouse Clicks)

Core Engine

6. Keyboard Automation

Keyboard automation sends arrow keypresses (UP, DOWN, LEFT, RIGHT) to the target VS Code window.

  • Directions are randomly selected for every event.
  • Executed via Win32 window messages.
Core Engine

7. Mouse Automation

Mouse automation is optional and executes left mouse clicks targeted inside the active VS Code editor text bounds.

Optimized Mouse Engine: Window activation is skipped if VS Code is already active. Mouse cursor movement is skipped if the pointer is already inside active editor bounds.
Core Engine

8. File Switching

File Switching executes Ctrl+Shift+Tab tab switches at minute transitions when enabled.

The user configures MIN and MAX file-switch bounds. At the end of each 60-second cycle, ArrowFlow executes consecutive tab switches according to the generated count.

10. Start / Stop

Clicking START AUTOMATION initializes the background thread and schedule queue. Clicking STOP AUTOMATION sets the thread cancellation flag, stopping all actions cleanly without leftover events.

Interface

11. Window & Taskbar Behavior

ArrowFlow launches visible on screen and in the Windows Taskbar by default.

Global Hotkey: Press ALT + SPACE anytime to toggle window and Taskbar button visibility.
Help

12. Troubleshooting

  • VS Code not appearing in list: Click the Refresh List button or ensure VS Code is not minimized.
  • Keypresses not registering: Ensure VS Code window handle is valid and active editor pane has cursor focus.
  • ESC key repeat: Built-in 350ms monotonic debouncing prevents accidental double toggles.
